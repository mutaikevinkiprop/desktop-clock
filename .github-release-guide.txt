# Desktop Clock v1.0.0

A lightweight, beautiful digital clock widget for Windows.

## ✨ Features

- ⏰ Real-time clock display
- 🌍 Multiple timezone support
- 🎨 Fully customizable appearance
- 📍 Precise multi-monitor positioning
- ⌨️ Global hotkey support
- 🚀 Optional launch-at-startup
- 💾 Lightweight and fast
- 🔒 Privacy-first (no data collection)

## 📥 Download

Choose one installer:

- **Desktop Clock_1.0.0_x64_en-US.msi** — Windows Installer (Recommended)
- **Desktop Clock_1.0.0_x64-setup.exe** — NSIS Installer (Alternative)

Both are per-user, no admin required, ~200 MB total size.

## 🚀 Quick Start

1. Download and run the installer
2. Clock appears on your desktop
3. Right-click system tray icon for settings
4. Customize appearance, timezones, and behavior

## 💻 System Requirements

- Windows 10 (1809+) or Windows 11
- x64 architecture
- ~200 MB disk space

## 🔒 Privacy

- ✅ No data collection
- ✅ No network connections
- ✅ No telemetry
- ✅ Settings stored locally only
